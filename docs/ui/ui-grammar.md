# Acorn UI grammar

## Visual thesis

**Clean institutional EdTech with modern AI accents.**

Education product first, AI-enabled product second.

## Teacher workflow grammar

- medium density, visually relaxed;
- master/detail and split views when context retention matters;
- list/table before card gallery for scan-heavy workflows;
- one primary task + 1–2 supporting regions;
- progressive disclosure for metadata/advanced controls;
- evidence before narrative explanation;
- recommendation is visually distinct from authoritative learner state;
- mascot appears selectively, never as decoration on serious evidence/review workspaces.

## Data visualization primitives

Use a small reusable grammar:

```text
horizontal bars
line trends
simple distribution bars
timelines
provenance lineage
```

Avoid novelty charts per screen.

## Density correction

The first mockup pass became too dense because “teacher UI is denser” was interpreted as “fit everything in one viewport.” The canonical correction is:

> **information-rich, visually relaxed**

Use readable type, fewer default columns, fewer visible rows and drawers/details instead of shrinking everything.
