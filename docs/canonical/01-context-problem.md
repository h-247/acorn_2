# 01 — Context & Problem

## For a new developer

This document explains the problem before the solution. Use it to check that a proposed feature reduces a real teacher/learner pain point or improves traceable institutional knowledge. A search box, dashboard or AI button is not automatically valuable unless it improves a step in the workflow below.

Keep the distinction clear: a stakeholder pain point is evidence, a requirement is an agreed behavior, and an implementation idea is only one possible solution. Do not promote an unvalidated assumption into a contract.

## Context

English centers often use similar commercial textbooks, exam sets, teacher-authored materials and external resources. Owning more files is not a durable differentiator. The valuable capability is turning common source material into center-specific teaching assets through structure, reuse, adaptation and evidence.

## Current workflow

```text
Find material
→ select suitable content
→ adapt for class/level
→ create exercise/assessment
→ assign
→ evaluate result
→ identify needs
→ find/create next material
```

## Problems

### P1 — High teacher preparation effort
Teachers repeatedly search, edit and recreate content. Existing adaptations are difficult to find and reuse.

### P2 — Materials do not accumulate as institutional assets
Teacher edits and effective teaching patterns can remain personal knowledge and disappear between cohorts.

### P3 — Learning results are not structurally linked to materials
A total score alone does not explain which skill/sub-skill needs attention or what content produced the evidence.

### P4 — Personalization can increase workload
Personalization only creates business value if the system reduces the incremental preparation cost for teachers.

### P5 — Learning evidence is not retained as institutional knowledge
Acorn should preserve a traceable journey:

```text
initial state
→ materials/assessments
→ evidence
→ teacher intervention
→ progression
→ outcome
```

## Problem statement

> Làm thế nào để một trung tâm Anh văn quản lý và khai thác vòng đời học liệu dựa trên learning evidence, qua đó giảm công sức chuẩn bị của giáo viên, hỗ trợ điều chỉnh nội dung theo nhu cầu học viên, và biến quá trình giảng dạy thành tri thức có thể tích lũy và tái sử dụng của trung tâm?

## Business baseline to collect

- teacher preparation hours/week;
- time-to-find material;
- time-to-create/adapt assessment;
- current material reuse practice;
- how teachers identify learner strengths/weaknesses;
- actual skill taxonomy;
- representative learner journeys/outcomes.
