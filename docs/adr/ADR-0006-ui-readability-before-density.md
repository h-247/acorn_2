# ADR-0006 — UI Readability Before Density

**Status:** Accepted

Teacher UI is **information-rich, visually relaxed**, not compressed.

Rules:
- body 15–16px;
- table 14–15px;
- captions generally ≥13px;
- default teacher row height 52–60px;
- ~6–7 visible table columns max on normal teacher screens;
- ~5–7 representative rows in design mockups;
- 4–5 primary filters + `More filters`;
- vertical scroll and progressive disclosure are preferable to shrinking type.

This ADR records the rendering issue found during initial Acorn mockups and prevents recurrence.
