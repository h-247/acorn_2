# Pilot / evaluation metrics

Acorn should collect enough evidence to evaluate workflow value without building a generic analytics platform.

## Baseline + after

- teacher preparation hours/week;
- time-to-find material;
- time-to-create assessment;
- time-to-adapt material.

## Material lifecycle

- direct reuse count/rate;
- adaptation count/rate;
- new creation count/rate.

## AI assistance

- generation success/failure;
- teacher accept without edit;
- accept after modification;
- reject;
- review duration.

## Recommendation

- accept / modify / reject;
- stale/regenerated count if implemented.

## Product evidence

Use a combination of:

```text
system metrics + observed task timing + teacher feedback
```

Do not claim causal learning effectiveness from observational progression alone.
