# `apps/web`

Target: Next.js + TypeScript Acorn application.

Primary teacher navigation:

```text
Home · Materials · Assessments · Classes · Learners
```

Student navigation is intentionally simpler.

Do not implement official learner-state calculation, authorization truth, recommendation logic, or AI orchestration in this app. Those belong to backend/application modules.

See `docs/ui/` and `packages/ui/` before implementation.
